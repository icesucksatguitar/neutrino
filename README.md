# Neutrino Browser

A minimal repository foundation for a planned desktop web browser.

> **Status:** Early repository setup. Browser implementation, UI development, and engine integration have not yet started.

---

## Intended Technical Direction

- **Browser Engine:** Firefox / Gecko
- **User Interface:** TypeScript, HTML, and CSS
- **Native Components:** Rust where appropriate
- **AI Integration (Planned):** Google Gemini

---

## Repository Structure

```text
neutrino/
├── app/               # Future TypeScript UI code and frontend assets
├── native/            # Future Rust native system components
├── docs/              # Architecture, setup, and research documentation
├── tests/             # Future automated tests
├── .github/workflows/ # Future CI/CD workflow configurations
├── .gitignore         # Standard ignore rules
└── README.md          # Project overview
```

---

## Development Status

This repository is currently in its initial structural setup phase. No browser features, mock screens, or engine builds are present. See [`docs/architecture.md`](docs/architecture.md) for architectural notes and research prerequisites.
